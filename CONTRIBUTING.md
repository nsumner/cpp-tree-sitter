# Contributing

For small fixes such as documentation improvements, typo corrections, or
straightforward bug fixes, feel free to open a pull request directly.


## Reporting Bugs

When reporting a bug, please include:

* A clear description of the problem.
* Steps to reproduce it.
* The expected behavior.
* The actual behavior.
* Relevant version information, operating system, compiler/interpreter
  version, or other environment details.
* Any error messages, logs, or stack traces that may help diagnose the issue.

A small, self-contained reproduction is appreciated when possible.
